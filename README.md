# 🚀 Guide de lancement de la mini-plateforme Cyber

Cette mini-plateforme en ligne a été développée avec le langage de programmation **Go (Golang)** dans le cadre d'un projet pédagogique en cybersécurité.

## 📥 Téléchargement

Téléchargez le fichier suivant :

* **cyber.exe**

## ▶️ Exécution de l'application

1. Double-cliquez sur **`cyber.exe`** pour lancer l'application.
2. Si Windows affiche un avertissement de sécurité :

   * Cliquez sur **« Informations complémentaires »**.
   * Puis cliquez sur **« Exécuter quand même »**.
3. Une fenêtre de console s'ouvre et le serveur démarre automatiquement.

Vous devriez voir un message similaire à :

```text
🚀 Serveur démarré sur http://localhost:8080
```

## 🌐 Accès à la plateforme

Une fois le serveur démarré :

1. Maintenez la touche **Ctrl** enfoncée.
2. Cliquez sur le lien suivant :

```text
http://localhost:8080
```

Ou copiez-collez cette adresse dans votre navigateur web préféré (Chrome, Firefox, Edge, etc.).

La plateforme sera alors accessible depuis votre navigateur.

## ⚠️ Remarques importantes

* Assurez-vous que le port **8080** n'est pas déjà utilisé par une autre application.
* Ne fermez pas la fenêtre de console tant que vous utilisez la plateforme.
* Pour arrêter le serveur, fermez simplement la fenêtre de console ou utilisez **Ctrl + C**.
